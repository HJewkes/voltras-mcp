- Replacing a planned exercise mid-block through `plan.exercise.create` now returns a
  `swapCheck` with the outgoing lift's top-load trend: still progressing says finish the block,
  since boredom is not grounds for a swap; flat or declining says the swap is supported and names
  the new exercise's novelty window. The edit is never blocked. A beginner block whose exercises
  are more than a quarter new against the previous block now warns.
