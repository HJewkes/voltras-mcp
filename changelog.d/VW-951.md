- A left/right pair now counts as one bilateral working set with two sides. The lighter side of
  an uneven pair used to be read as a warm-up, so the Review page marked it "not scored" with no
  e1RM, and `plan.suggest_progression` and `report.session_results` scored the heavier side
  alone. Both sides are now scored, a lighter ramp-up pair is still left out, and the Review
  page labels each side `L` or `R` on the set strip and in the set table (VW-951).
