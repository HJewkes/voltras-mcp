section: Changed
---

- A set that auto-arm opens against a planned exercise now carries that plan row's velocity-loss
  watch without an agent: the row's own loss target when it names one, else its training intent's
  default (strength 20%, hypertrophy 30%, power 10%). The watch lands a moment after the arm, is
  announced with `set_updated`, and a later `set.start` still upgrades the set once and replaces it.
  A set with no plan row is unchanged (VW-718).
