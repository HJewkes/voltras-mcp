- `plan.respond_deload_advisory` files the lifter's yes or no to a recovery rung that
  `plan.next_workout` advised. It records the answer and changes nothing else: accepting never
  edits the plan. An answered rung, accepted or declined, is not offered again on the same
  evidence, and a repeat answer records nothing; a newer session that shows the decline again
  for some muscle brings it back. `deloadAdvisory` names the tool on `advise` only.
