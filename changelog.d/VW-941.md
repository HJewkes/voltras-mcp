- `npm run store -- anonymize` turns a store export into a private anonymised fixture on
  your own machine. It removes free text, renames programs and custom exercises, replaces
  device ids and lifter labels with stand-ins, and moves every date by whole weeks. The output
  is still personal training data, so it refuses to write inside a git work tree. See
  [Make a private anonymised fixture](/guides/troubleshooting#make-a-private-anonymised-fixture) (VW-941).
