- `VMCP_CUES_MIDSET=risk` lets mid-set cues speak only through the cue-delivery layer
  (`VMCP_CUE_DELIVERY=on`), and only on a set whose risk reading at set start is green. Amber
  and red sets, and sets with no reading, stay silent mid-set, and the default cues never speak
  mid-set under `risk`. `system.set_cues` accepts `midSet: risk`, and `server.health` reports
  it. A set whose earlier set of the same exercise was recorded by an older server version reads
  its fatigue as unknown and stays silent mid-set. The default stays `off` (VW-614).
